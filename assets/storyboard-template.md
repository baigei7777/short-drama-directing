## 「拍摄备注」列怎么写

**每一镜都必须写，不许留空。** 这一列装的是**不进生成提示词、但对成片有影响**的执行提示。写它的意义是：生成时不用动脑子，剪辑时照着做。

用图标标出类别，方便筛选：

| 标记 | 类别 | 写什么 | 例子 |
|:---:|---|---|---|
| ⚠️ | **生成风险** | 这一镜最容易崩的地方，**并给一个备选拍法** | `掌掴接触瞬间容易崩手部结构。备选改拍"甩手挥出→切脸部受力特写"，避开接触帧` |
| 🔒 | **连续性锁** | 跨镜、跨集不能变的东西 | `唇角血丝的位置与面积与 S2 完全一致，不能变淡也不能扩大` |
| 📌 | **后期处理** | 后期要贴的字、要对位的音效、要加的层 | `后期在手机屏幕位置贴短信文字。本镜不生成任何画面文字` |
| 📐 | **UI 安全区** | 竖屏顶部 20% / 底部 15% 的构图约束 | `人物在画面中段以下，避开底部 15%（否则会被按钮压住）` |
| 🎭 | **表演要点** | 关键表演提示、速度指令、"不要演成什么" | `关键是不躲不闪，不要演出畏缩——她的硬气就在这一下` |

**四种最常见的备注**，几乎每集都会用到：

1. **字幕归后期** —— 剧本里的 `【字幕：…】`、手机短信、名片地址、屏幕信息，全部写进备注交给后期，**提示词里一个画面文字都不出现**（见 `references/sd25-contract.md` 的负向控制一节）
2. **借位替身** —— 打斗、掌掴、砸击类镜头，写明"用借位/掠过，不拍实打接触"
3. **情绪峰值标记** —— 该镜是全集峰值时写明情绪值，并提示"这里的慢是刻意的，不要剪短"
4. **收尾镜构图** —— 拉高/俯视类收尾镜，写明人物避开 UI 遮挡区

## 交付前自检

- [ ] **剧本覆盖率已核对**：剧本里**每一句台词**（含 OS）和**每一行动作**都能在本表里找到对应位置。**动过单元数量就必须重查**（见 `references/workflow.md` 第 0 节）
- [ ] 骨架只用了一种（镜头序列 / 阶段 / 一镜到底），没有混用
- [ ] 每个单元的时间轴首尾相接、连续无空洞
- [ ] 每个单元的所有镜头时长总和 = 该单元生成时长，且 ≤ 30 秒
- [ ] 单镜时长 = 成片需要（台词镜被台词长度撑着，动作镜可短到 1.5–2 秒）；没有低于 1 秒的镜头，也没有把短内容硬垫到 4 秒的镜头
- [ ] 每镜只有一个主动作 + 一个运镜
- [ ] 每镜结束在完成态，下一镜能接上
- [ ] 台词落在说话人出镜的镜头里，与音频参考对得上
- [ ] 每个单元的上传顺序与素材绑定已写全
- [ ] **每一镜都有拍摄备注，没有留空**
- [ ] 画幅已写死
- [ ] 估算时长已标 `待核`
