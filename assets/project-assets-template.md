# 全剧资产总表模板

> **项目首次开工时建一次**，之后每一集都复用。不要每集重新起名——重新起名会让跨集一致性直接崩掉。
> 复制本文件填成 `00-全剧资产/00-资产总表.md`（全剧资产都放在 `00-全剧资产/` 目录下，分镜与提示词另放 `01-分镜/` 和 `02-提示词/`）。
>
> **字段规范与出图提示词写法见 `references/asset-pipeline.md`。**

---

## 结构铁律（**先读这条，它决定整份表的形状**）

1. **出图提示词写在每个条目下面**——人物跟在人物条目下、场景跟在场景条目下、道具跟在道具条目下。
   **不要**攒成一节"出图提示词汇总"，**更不要**另建一个全剧出图提示词文件。看一个角色，就要能在一个地方同时看到他的档案与提示词。
2. **不要用大宽表把多个角色 / 场景 / 道具挤成一行。**
   markdown 表格里塞不进多行代码围栏，一旦用表，提示词就只能被挪到别处——那就正好违反第 1 条。
   **每个角色 / 场景 / 道具各起一个 `###` 标题**，字段用引用行或两列小表列在下面，提示词紧随其后。
3. **一个条目的固定顺序**：`###` 标题 → 字段 → `**出图提示词（N 张）**` → **每张图一个 `####` 标题 + 提示词正文**。
4. **"一图一参考"**：有几个视角 / 状态就写几条，绝不合并成一条、也绝不拼成一张图。
5. 建表时**顺手把提示词一起写完**——不要"先建表，以后有空再补提示词"，那正是提示词被挪走的起点。

## 1. 命名规范（先定这个，后面所有表都照它）

**人物**：`C-<拼音缩写>-<序号>`　例：`C-LW-01`（林晚）、`C-ZY-01`（周砚）

**同一角色的不同形态**加后缀：`C-JJ-01-M`（男装）／ `C-JJ-01-F`（女装）

**场景**：`S-<地点拼音>-<序号>`　例：`S-KT-01`（客厅）

**站位**：`B-<集号>-<场号>`　例：`B-E01-01`

**配音**：`A-<角色缩写>-<集号><序>`　例：`A-LW-E01-01`；声线档案：`V-<角色缩写>-<序号>`

**道具**：`P-<名称拼音>-<序号>`　例：`P-HJ-01`（婚戒）

**生成单元**：`U<两位集号>-<两位序号>`　例：`U01-01`。**用集号前缀，不用全剧连续编号**——分镜常常跳着做集，连续编号会失效。

**镜头**：`<单元号>-S<两位>`　例：`U01-01-S03`

**文件**：`E<集号>-分镜表.md`、`E<集号>-prompts.txt`

## 2. 人物资产

### 分两层记，不要所有角色一个规格

| 层级 | 谁 | 记什么 |
|---|---|---|
| **完整档案** | 主角 + 主要配角（约 10–15 人） | 下面全部字段 |
| **精简档案** | 功能性配角、群演 | 只记三行：**体型 / 标志性标记 / 招牌动作** |

### 2.1 完整档案

> 每个字段的填写规范与示例见 `references/asset-pipeline.md` 第 2.1 节。
> **两条硬规则：不写服装**（服装属于 prompt 的【主体设定】）、**不写镜头与色彩**。

**一个角色一条 `###` 标题，字段和提示词挨在一起**：

````
### C-___-__　<角色名>

**外观**：<年龄段>、<体型>、<面部特征>、<发型>、<胡须/标记>
**体型履历**：<让身体读出职业 / 旧伤 / 自我认知>
**心理引擎**：<一句话说清驱动身体的内在动力>
**招牌小动作 + 触发**：<动作>——<什么时候做>
**压力小动作 + 触发**：<动作>——<什么时候做>
**掩饰行为**：<他用什么藏住真实反应>
**面具与裂缝**：<伪装是什么>；但<什么条件>会击穿它——<具体会怎样>
**步态**：<可写的具体走法，不只是"走路">
**软化对象**：<**只给一个**人 / 动物 / 物件>

**出图提示词（3 张）**          ← 就在本条目下面，不挪到别处

> **共享【主体】**：…（**同一角色的多张图共用这一段**，它是"同一人"的唯一保证）
> **共享【服装】**：…
> **共享【色板】**：…

#### C-___-__ · 正面全身        ← 每张图一个标题，下面是完整提示词
【用途】…【主体】…【服装】…【姿态与构图】…【背景】…【光线】…【质感】…【色板】…【禁止项，写成正向】…

#### C-___-__ · 面部中性
…

#### C-___-__ · 面部强烈情绪
…
````

> ℹ️ 如果某个角色有**跨集不变的服装锁**（例：同一人两套造型），在字段里加一条 `**服装（N 套，跨集锁死）**`，把两套写清；**日常服装仍然写在提示词的【服装】字段里**。

**四条填写要点**：

1. **不写"他很紧张"**——写身体标记（下唇在抖、喉结滚动、用嘴长吸气）
2. **每个小动作都要带触发条件**，孤立动作清单是装饰，带触发条件的才是戏
3. **面具必须写裂缝**——至少一个"但 X 的时候……"的条件转折，这是最电影的装置
4. **软化对象只给一个**，多了会稀释

### 2.2 精简档案（功能性配角 / 群演）

**一人一条 `###` 标题，不要挤成一张表**（表里装不下提示词）：

````
### C-___-__　<名字>

> **体型**：<年龄段>、<身形>
> **标志性标记**：<一眼能认出他的东西>
> **招牌动作**：<动作>——<触发>
> **出现集**：E__, E__

**出图提示词（1 张）**

#### C-___-__ · 正面全身
【用途】功能性配角定妆参考图。一次一张，不拼图。
【主体】…【服装】…【姿态与构图】…【背景】…【光线】…【质感】…【色板】…【禁止项，写成正向】…
````

### 2.3 出图所需的视角清单

**要几个视角就出几张图，绝对不要拼成一张**（Seedance 侧要求一图一参考）。

| 视角 | 用途 | 是否需要 |
|---|---|---|
| 正面全身 | 主参考 | **必须** |
| 面部特写 · 中性 | 锁五官 | 建议 |
| 面部特写 · **强烈情绪** | 让模型学到面部动态与牙齿 | **强烈建议** |
| 背面全身 | 锁发型与服装背面 | 按需 |
| 侧面全身 | 锁轮廓 | 按需 |

**出图规范**：中性浅灰背景、无陈设、柔和定向光；**不要写** `painterly`、`概念设定图`、`character reference sheet`（会触发插画漂移）。

## 3. 场景资产

**一个场景一条 `###` 标题**，字段用两列小表列在下面，提示词紧随其后：

````
### S-___-__ <场景名>
> 出现 __ 集（E__, …）｜**剧本依据**：<剧本里能指认的空间 / 物件 / 光线证据，带场次号>

| 字段 | 内容 |
|---|---|
| **空间与建筑** |  |
| **光线**（跨集锁死） |  |
| **主色板 60/30/10** | `60% __ + 30% __ + 10% __` |
| **材质** |  |
| **绝对不要继承的** | 参考图中的人物、机位、构图 |

> 剧本未写，以下为设定建议：…

**出图提示词（1 张）**

#### S-___-__ <场景名>
【用途】场景环境参考图。
【相机】…（**简单胜过抽象**：只写真实器材 + 摄影机位置与朝向）
【空间】…【光线】…【材质】…【色板】…【空景】…【质感】…
````

**出图规范**：

- **相机锚句是难点**：简单胜过抽象。写 `高角度四分之三广角，摄影机位于房间上方，斜向下 45 度俯视`，不要写 `CCTV 视角`、`鱼眼`
- **场景图尽量不要人**。要空就写"空无一人的室内，光秃的墙面，静止的空气"，**不要**写"没有人"
- **不要**在场景图上用镜头光学词汇（景深、焦外、虚化）——那是人物的活

## 5. 配音资产 · **声线档案**

> **这是给配音录制与选声用的，不进 prompt。**
> prompt 里锁音色靠**音频参考**，不靠文字描述声线。

### 5.1 声线档案

| 编号 | 角色 | 音高与音色 | 语速与节奏 | 停顿习惯 | 口头禅/语言习惯 | 情绪基底（压力下往哪变） | 对照参考（描述性特征） |
|---|---|---|---|---|---|---|---|
| V-___-__ |  |  |  |  |  |  | **不写真人姓名** |

### 5.2 每集配音量

| 编号 | 角色 | 集号 | 台词范围 | 时长 | 音频文件 | OS 还是对白 |
|---|---|---|---|---|---|---|
| A-___-E01-01 |  | E01 |  |  |  | 对白 / **OS** |

**三条录制规范**：

1. 单个生成单元的音频建议 **5–10 秒**；超过 10 秒按气口拆段，并在分镜里拆成多个镜头
2. **OS（内心独白）单独一轨**，后期做近距离耳语处理，与现场对白要有音色区别
3. 拆音**以气口为准**，不要按标点硬切，否则口型对不上

## 6. 道具资产

**一件道具一条 `###` 标题**，字段用引用行列在下面，**多状态各写一段提示词**：

````
### P-___-__　<道具名>

> **结构与材质**：…
> **归属**：…（**一件只属一个所有者**）
> **关键性**：高 / 中 / 低
> **多状态**：①<状态名> ②<状态名>
> **出现镜头/集**：…

**出图提示词（2 个状态 · 每个状态单独出图）**

**① <状态名>**

```
【用途】道具参考图。
【主体】…【取景】…【背景】…【光线】…【质感】…
【无标识，写成正向】素面无字表面，干净的哑光材质。
```

**② <状态名>**

```
…
```
````

**三条规范**：

1. **每个状态单独出图**，不要在一张图里画三个状态
2. **敏感道具要做措辞替换**：某些道具名会触发内容拦截，用中性的材料与功能描述代替（不写"枪械零件"，写"复古工业电子组件，带数字读数窗"）
3. **要无 logo 就正向写**：`素面无字表面，干净的哑光材质`，**不要**写"不要 logo"

## 7. 跨集连续性锁

这些是跨集不能变的东西，写在这里，每集都照抄进 prompt 的【整体要求】：

- 人物发型、服装、标志性配饰
- 伤痕/血迹的**位置与颜色**（位置变了就是穿帮）
- 场景的光线基调与色温
- 全剧的画幅与调色基调
- 主角入画方向

## 9. 合规备注

- **参考素材授权**：只用自有、已授权、公有领域或明确许可的素材做形象/声音/品牌转移
- **不写真人姓名**：把参考人转译成描述性特征（脸型、体型、气质、年代）
- **不写 IP / 品牌名**：任何位置都不写
- **风格安全**：不要写具体工作室、作品名或在世画师
- **微短剧备案/审核**：上线前按主管部门现行规定完成备案——这一项与画面无关，但决定整部剧能不能上线，建项目时就该确认
