## 1. 命名规范（先定这个，后面所有表都照它）

**人物**：`C-<拼音缩写>-<序号>`　例：`C-LW-01`（林晚）、`C-ZY-01`（周砚）

**场景**：`S-<地点拼音>-<序号>`　例：`S-KT-01`（客厅）、`S-BGS-01`（办公室）

**站位**：`B-<集号>-<场号>`　例：`B-E01-01`

**配音**：`A-<角色缩写>-<集号><序>`　例：`A-LW-E01-01`

**道具**：`P-<名称拼音>-<序号>`　例：`P-HJ-01`（婚戒）

**生成单元**：`U<全剧连续序号>`　例：`U01`、`U02`……**跨集连续编号，不按集重置**，这样续写和复用素材时不会乱。

**镜头**：`<单元号>-S<序号>`　例：`U01-S3`

**文件**：`E<集号>-分镜表.md`、`E<集号>-prompts.txt`

## 2. 人物资产

| 编号 | 角色名 | 定位 | 形象参考图 | 音色/配音 | 服装描述（跨集一致） | 首次出场 |
|---|---|---|---|---|---|---|
| C-LW-01 | 林晚 | 女主 | `图-C-LW-01.jpg` | A-LW | 米白针织衫 + 左手婚戒 | E01 |
| C-ZY-01 | 周砚 | 男主 | `图-C-ZY-01.jpg` | A-ZY | 深色衬衫 + 右手腕表 | E01 |
|  |  |  |  |  |  |  |

**每个角色的形象参考图要求**：单人、正脸或轻微侧脸、光线均匀、背景干净。**超过 5 个角色同时出场时改用单视图**；需要多视角就拆成多张图分别传，不要传一张含多视角的图。

**角色描述要写死的部分**（每个单元 prompt 里都要重复）：发型、发饰、年龄感、标志性配饰、常服颜色。

### 需要多视角时（2.5 独有能力）

**每一个角度都要占用 30 个图片名额里的一个**，所以别滥用。

- **超过 5 个角色，停止一人多视角**，改用**角色设定图 + 主体档案**锁定身份
- **绝对不要把多个视角拼成一张图**——必须拆成独立图片分别传
- 每条视角都要显式声明，最后用一句收口：`以上四张图定义同一个 <林晚>。整段输出中只能出现这一个这样的人。`

**出图时的三条建议**（直接转告用户）：

1. 每个视角都在**中性浅灰背景**上生成
2. **务必包含一帧强烈表情**（发怒或大笑），让模型学到面部动态与牙齿结构，而不只是静止的脸
3. 需要多视角但主体超过 5 个时，改用单视图更稳

### 主体档案（角色跨集反复出现时）

在 prompt 里用的版本（登记表是人看的，档案是塞进 prompt 的）：

```
[主体档案：林晚] 外观与服装：图1。固定道具：<婚戒> 来自 图4。
活动场景：<别墅客厅>、<门外台阶>。运动参考：视频1 的摔手机动作。
不要使用：其他角色的服装。
```

## 7. 跨集连续性锁

这些是跨集不能变的东西，写在这里，每集都照抄进 prompt 的【整体要求】：

- 人物发型、服装、标志性配饰
- 伤痕/血迹的位置与颜色（位置变了就是穿帮）
- 场景的光线基调与色温
- 全剧的画幅与调色基调
- 主角入画方向

## 8. 合规备注

- 平台审核红线（画面规避）见 `references/type-short-drama.md` 与项目决定
- 微短剧备案/审核要求：**上线前按主管部门现行规定完成备案**。这一项与画面无关，但会决定整部剧能不能上线，建项目时就该确认
- 参考素材使用授权：只用自有、已授权、公有领域或明确许可的素材做形象/声音/品牌转移
- 风格安全：**不要写具体工作室、作品名或在世画师**
