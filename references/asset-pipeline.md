# 资产与出图

本文件管三件事：**资产表该记什么字段**、**参考图怎么出**、**素材交付规范**。

它和 `ref-binding.md` 的分工：

| 文件 | 管什么 |
|---|---|
| **本文件** | 怎么**产出**参考图（出图提示词）、资产表要登记什么 |
| `ref-binding.md` | 怎么把已有的参考图**绑进镜头**（编号、角色分工、转移/忽略） |

**先有图，才有绑定。** 顺序不能倒。

---

## 一、什么时候用

**项目首次开工时，默认走一遍**：剧本 → 资产表 → 出图提示词 → 然后才进每集的分镜。

**可以跳过**：用户明确说"图我自己出"或"这次只做分镜"时，跳过出图，只建资产表。

---

## 二、资产表字段规范

> 🚧 **形状先定死（与 `assets/project-assets-template.md` 顶部「结构铁律」一致）**：
> **每个角色 / 场景 / 道具各起一个 `###` 标题，它的出图提示词就写在这个条目下面。**
> **不要**用大宽表把多项挤成一行——markdown 表格装不下代码围栏，一用表提示词就只能被挪走；也**不要**另建"全剧出图提示词"文件。
> 下面每个小节里的「出图提示词」一栏，指的就是**本条目下面那一段**。

命名规范见 `assets/project-assets-template.md`。下面是**每类资产该记什么**。

### 2.1 人物资产

**分两层记**，不要所有角色一个规格：

| 层级 | 谁 | 记什么 |
|---|---|---|
| **完整档案** | 主角 + 主要配角（约 10–15 人） | 下面全部字段 |
| **精简档案** | 功能性配角、群演 | 只记三行：**体型 / 标志性标记 / 招牌动作** |

**完整档案的字段**（按这个顺序写）：

| 字段 | 填什么 | 举例 |
|---|---|---|
| 编号 / 名字 | 见命名规范 | `C-JJ-01-M` 纪谨（男装形态） |
| **外观** | 年龄段、体型、面部特征、发型、胡须、标志性标记 | 十八岁、清瘦少年体型、下颌线偏尖、短碎发、左眉尾有疤 |
| **体型履历** | 让身体读出职业 / 旧伤 / 自我认知 | 拳击训练出的肩背线条，但长期营养不良显得单薄 |
| **心理引擎** | 一句话说清驱动身体的内在动力 | 十岁起在拳馆学会：规则清楚的地方才安全 |
| **声线** | 见 2.3，单独一张表 | — |
| **招牌小动作 + 触发条件** | **必须带触发条件**，不能只列动作 | 攥拳头——在必须低头但不能低头的时候 |
| **压力小动作 + 触发条件** | 同上 | 舔嘴唇——在准备说谎或硬撑之前 |
| **掩饰行为** | 他用什么动作藏住真实反应 | 面无表情、语速放慢、把视线移到远处 |
| **面具与裂缝** | 伪装是什么 + **什么条件会击穿它** | 全程清冷毒舌；但**只要有人提到"妈妈"两个字**，下颌会绷一下，眼神散掉半秒 |
| **步态** | 给出可写的具体走法，不只是"走路" | 步子大、落脚重、上身几乎不晃——拳馆里练出来的直线走法 |
| **软化对象** | **只给一个**人 / 动物 / 物件 | 容盛拳馆前台那只老猫 |

**两条硬规则**：

1. **不写服装。** 服装属于 prompt 的【主体设定】，不属于表演档案。档案要能在换装后依然成立。
2. **不写镜头、不写色彩。** 表演档案只管表演、面部、声音、动作。

> ⚠️ **不要写"他很紧张"**——要写**身体标记**：下唇在抖、喉结重重滚动一下、用嘴长长吸气再从抿紧的嘴唇里急促呼出。
> **每一个内心状态都要有对应的身体标记**，否则模型无从下手。

### 2.2 场景资产

| 字段 | 填什么 |
|---|---|
| 编号 / 名字 | `S-JJKT-01` 纪家客厅 |
| **空间与建筑** | 布局、固定家具、门窗位置 |
| **光线**（**跨集锁死**） | 主光方向 + 色温 + 明暗关系 |
| **主色板** | 60/30/10 三色，用**真色名**，不要"高级灰"这类空话 |
| **材质** | 真实材料 + 表面状态（`板模混凝土`、`氧化发绿的铜`） |
| **绝对不要继承的** | 从参考图里**不要**取的东西（一般是：图中的人物、机位、构图） |
| **出图提示词** | 见第三节；**写在本条目下面** |

### 2.3 音频资产 · **声线档案**

每个有台词的角色一份。**这是给配音录制与选声用的，不进 prompt**（prompt 里锁音色靠**音频参考**，不靠文字）。

| 字段 | 填什么 |
|---|---|
| 编号 | `V-JJ-01` |
| **音高与音色** | 低沉沙哑的中音 / 清亮偏冷的少年音 … |
| **语速与节奏** | 常态语速；以及在什么情况下会变 |
| **停顿习惯** | 句间停顿长短、有没有惯用的拖音 |
| **口头禅 / 语言习惯** | 重复问句、突然换话题、回答过短 … |
| **情绪基底** | 平时是什么状态；**压力下会往哪个方向变**（变轻？变慢？变冷？） |
| **对照参考** | 用描述性特征写，**不要写真人姓名** |

**还要记**：

- 同一角色的 OS（内心独白）与现场对白要**分开标注**——OS 后期做近距离耳语处理，音色与对白要有区别
- 单条音频建议 **5–10 秒**；超过 10 秒按气口拆段，并在分镜里拆成多个镜头

### 2.4 道具资产

| 字段 | 填什么 |
|---|---|
| 编号 / 名字 | `P-ZP-01` 拳馆女装照片 |
| **结构与材质** | 形状、材料、颜色、磨损状态 |
| **归属** | 属于谁（**一件道具只属于一个所有者**） |
| **关键性** | 会不会被特写？会不会易手？→ 决定要不要单独出图 |
| **多状态** | 干净 / 破损 / 带血 … **每个状态是独立的一张资产图**，不是一张图里画三遍 |
| **出图提示词** | 见第三节；**写在本条目下面** |

## 三、出图提示词怎么写

### 3.1 动手前先在内部过一遍（不外泄）

1. **拆解** —— 要出的是什么？人物 / 场景 / 道具？是**生成**还是**改已有一张图**？画幅和分辨率是平台参数还是写进提示词？
2. **诊断** —— 缺什么信息？有没有已知的失败风险（插画漂移、多人物塌陷、提示词灌水、真人/IP 风险）？
3. **构建** —— 选对应模板，套下面的通用规则。
4. **交付** —— 先给提示词，再给简短的"这段里我埋了什么"。

### 3.2 五条通用硬规则

**① 写连贯的自然语言，不堆关键词。**
`4k, masterpiece, best quality, trending` 这类词**没有任何作用**。用一句连贯的画面描述代替。

**② 不灌水。**
精准胜过啰嗦。一段紧凑的 **150–250 字中文**胜过散乱的 800 字——超出之后每多一个从句都会稀释注意力，细节开始掉。目标总量 **≤1500–2000 字符**（这个上限是按经验值给的，**不是平台保证**）。

**③ 正向优于负向。**
图像模型**普遍没有负面提示词参数**，而且写"不要 X"反而会把 X 塞进模型脑子里。
- ❌ `不要卡通，不要动漫，不要插画` → 这三个词全被激活
- ✅ `写实电影剧照质感，实拍胶片颗粒，真实皮肤纹理`
- ❌ `不要痘痘` → ✅ `皮肤干净干燥`
- ❌ `街上没人` → ✅ `空无一人的街道，光秃的墙面，静止的空气`

**在编辑任务里，"删除"是合法操作**（`去掉路灯`），但**必须同时说明空出来的位置由什么占据**（`后面是连续的砖墙`）。

**④ 画幅和分辨率是平台参数。**
**不要写进提示词**（不要 `--ar`、不要正文里写 `16:9`、不要写 `4K`）。要用**构图词**表达：

| 不要写 | 改成 |
|---|---|
| `9:16` | `竖幅全身构图` |
| `16:9` | `宽幅全景` |
| `21:9` | `宽银幕横幅` |
| `1:1` | `方形构图，主体居中` |

> ⚠️ **注意与视频的分工**：**Seedance 参考生视频是"无锁定"任务，那里必须把画幅写死在提示词里**（见 `sd25-contract.md` 第 2 节）。这条"走平台参数"只适用于**出图**。

**⑤ 具体的光和材质，不要空泛的"氛围"。**
- ❌ `戏剧性的电影感光线` → ✅ `顶部单主光，光比约 2:1，柔和衰减`
- ❌ `高级材质` → ✅ `板模混凝土，表面有脱模留下的木纹`

**打光三件套**：单一主光 + 光比 + 衰减。缺一个都会变成平光。

**色板用百分比**：`60% 暖赭石 + 30% 深炭灰 + 10% 锈红`。
**色板必须从剧本、场景设定或你已有的参考图里推出来，不要在参考图之上自己另起一套。**

### 3.3 三种资产的出图模板

#### 模板 A · 人物定妆图（**一次一张，不要拼图**）

> ⚠️ **关键约束**：Seedance 侧要求**一张图一个参考**，所以**绝对不要把正/背/特写合成一张**（见 `ref-binding.md` 第 6 节）。要几个视角就出几张。
> 但**需要哪些视角**要提前列清，一次把视角清单定下来。

**视角清单**（按需选，主角建议 3–4 张）：

| 视角 | 用途 | 是否必须 |
|---|---|---|
| 正面全身 | 主参考，锁形象与体型 | **必须** |
| 面部特写 · 中性表情 | 锁五官 | 建议 |
| 面部特写 · 强烈情绪 | **让模型学到面部动态与牙齿**，不只是静止的脸 | **强烈建议** |
| 背面全身 | 锁发型、服装背面 | 按需 |
| 侧面全身 | 锁轮廓 | 按需 |

**提示词骨架**：

```
【用途】人物定妆参考图，用于后续视频生成的角色一致性参考。
【主体】<年龄>、<体型>、<面部特征>、<发型>、<胡须/标记>。
【服装】<这一形态的固定服装，逐项写清>。
【姿态与构图】<正面全身站立，双手自然垂放，从头到脚完整入画>。
【背景】中性浅灰背景，无任何陈设。
【光线】柔和定向光从一侧来，面部明暗过渡自然，无生硬阴影。
【质感】写实摄影质感，真实皮肤纹理，干净干燥的皮肤，<胶片颗粒 或 干净数字质感>。
【色板】主色 <A>，辅助色 <B>，点缀色 <C>。
【禁止项，写成正向】背景干净无杂物；画面中不出现任何文字。
```

**四条要点**：

1. **背景用中性浅灰、无陈设**——定妆图要当身份参考，背景越干净越好
2. **要有一张强烈表情的帧**（发怒或大笑），让模型学到面部动态与牙齿结构
3. **不要写** `character reference sheet`、`painterly`、`概念设定图`、`插画`——**这些词会触发插画风漂移**。要写 `电影剧照`、`写实摄影`
4. **同一个角色的多张视角图，要在每张里都重复同一句身份声明**（`这是 <角色名> 的正面全身参考图`），并用同一段外观描述

#### 模板 B · 场景图

**相机锚句是场景图最难的一环，也是最容易写坏的**。

- ✅ **简单胜过抽象**：`高角度四分之三广角，摄影机位于房间上方，斜向下 45 度俯视`
- ❌ 抽象术语：`CCTV 视角`、`鱼眼`、`极端荷兰角`——这类词经常失败或过度畸变
- **用真实器材 + 类型词**比抽象几何好用：`24mm 广角，房产室内摄影风格`
- **地面纹理这类顽固几何**：用正向描述重述（`横向条纹图案，地面没有消失点`），不要硬碰

**提示词骨架**：

```
【用途】场景环境参考图。
【相机】<相机锚句>。
【空间】<地点身份>。<关键建筑/自然元素>。<次级元素向纵深后退>。
【光线】<光源 + 方向 + 色温>。
【材质】<真实材料 + 表面状态>。
【色板】主色 <A>，辅助色 <B>，点缀色 <C>。
【空景】<如果场景必须空，用正向写：空无一人的室内，光秃的墙面，静止的空气>。
【质感】<胶片颗粒 或 干净数字质感>。
```

**三条要点**：

1. **场景图尽量不要人。** 要空就说"空无一人"，**不要**说"没有人"
2. **不要继承参考图里的人物、机位、构图**——在绑定的时候要写明（见 `ref-binding.md` 第 5 节）
3. **不要把镜头光学词汇（景深、焦外、虚化）用在场景图上**，那是人物的活

#### 模板 C · 道具图

```
【用途】道具参考图。
【主体】<道具名>，<结构与材质>，<磨损状态>。
【取景】<俯视平铺 或 四分之三俯角>产品式取景，主体孤立居中。
【背景】中性灰色台面。
【光线】柔和定向光。
【质感】写实产品摄影质感。
【无标识，写成正向】素面无字表面，干净的哑光材质。
```

**三条要点**：

1. **每个状态单独出图**（干净 / 破损 / 带血），不要在一张图里画三个状态
2. **道具要写清"结构与材质 + 颜色"**，不要只写名字
3. ⚠️ **敏感道具要做措辞替换**：某些道具名会触发内容拦截。**用中性的材料与功能描述代替**——例如不写"枪械零件"，写"复古工业电子组件，带数字读数窗"

## 四、改图（编辑已有素材）

**改图和出图是两条不同的路。** 改图的第一原则：

> **改图 = 对原图的后处理，不是重画。只改最小的那一处，其他一切逐项锁死。**

**永远不要用"改图"去重建一张图**——需要重建就重新生成。

### 三段式模板

```
编辑这张图：<一句话说明目标>。

【唯一改动】<只描述要变的那一件事，写精确>。

【穷举保留】
- <逐项列出必须完全不变的：面部、服装、道具、位置、墙面/地面、机位、所有已有阴影>
- 调色、色板、对比度、颗粒、光衰减

【收口复述】只改 <复述那一件事>。除此之外 100% 与原因相同。
```

**一次只改一处。** 要改两件事就分两次。

### 改图失控时怎么归因

用户说"你改多了"或"跑偏了"——**那一定是你改了太多**。

处理：**把 PRESERVE 清单写得更穷举，把唯一改动写得更小。锁更多，改更少。**

### 场景换视角（反打 / 换机位）

换视角**不是普通编辑**——必须**逐一交代每个物体在新视角里的位置**，否则几何会乱：

```
主视角里沙发在画面右侧；这个反打视角里沙发在画面【左侧】，
原本在摄影机背后的门现在出现在画面前方。
```

**每一个主要物体都要交代新位置**，不能只写一句"换成反打"。

## 五、素材交付规范

| 项目 | 规范 |
|---|---|
| **画幅** | 出图走平台参数；**视频**（Seedance 参考生视频）写死 9:16 或 16:9 |
| **一图一参考** | 绝对不要把多个视角合成一张拼图 |
| **背景** | 定妆图与道具图用中性背景；场景图不要人 |
| **文字** | 参考图里**不要出现任何文字**（字幕、标牌、屏幕内容一律后期加） |
| **真人 / IP** | **不写真人姓名**（把参考人转译成描述性特征：脸型、体型、气质、年代）；**不写 IP / 品牌名** |
| **一致性** | 同一个角色 / 场景 / 道具，在同一个项目里**保持同一套句式与色板**，不要每次换写法 |

## 六、出图后的自检清单

- [ ] **该拆的拆了**：没有多视角拼图；道具的多状态是分开的
- [ ] **画幅没写进提示词**（走平台参数），或者这是视频任务、画幅已写死
- [ ] **没有负向堆叠**：想排除的东西都改成了正向描述
- [ ] **光线三件套齐了**：主光 + 光比 + 衰减
- [ ] **材质是具体的**材料 + 表面状态，不是空泛形容词
- [ ] **色板是从设定推出来的**，不是在参考图之上另起一套
- [ ] **没有真人姓名、没有 IP / 品牌名**
- [ ] **没有插画触发词**（写实向：不要 `painterly`、`概念设定图`、`插画`）
- [ ] **提示词不臃肿**：150–250 字左右，总量不过千
- [ ] **每个角色：每个内心状态都有对应的身体标记**，没有"他很紧张"这类直接写情绪的句子
- [ ] **每个小动作都带触发条件**（什么时候做），不是孤立的动作清单
- [ ] **面具写了裂缝**：至少有一个"但当 X 的时候……"的条件转折
