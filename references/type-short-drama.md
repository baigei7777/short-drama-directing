# 短剧档（9:16 竖屏）

用户回答"做的是**短剧**"时读本文件。开工前已经把配音、参考图、剧本点清（见 `references/workflow.md` 的 A 节）。

---

## A. 切镜速度 / 平均镜头时长

**短剧的节奏特征：镜头多、台词密、动作镜短。**

- **台词镜**：时长被台词长度撑着，压不动。台词长度 + 0.5–1.0 秒缓冲
- **动作镜 / 反应镜**：这是短剧"快"的真正来源——可以短到 **1.5–2 秒**（一记耳光、一次砸击、一个转身、一个冷笑）
- 情绪值普遍偏高：短剧一集里 6–8 分是常态，8–10 分的峰值集均出现 2–3 次
- 情绪值 1–3 的铺垫段单镜可以到 4–5 秒，但**不要超过一集总时长的 1/4**，否则观众划走
- **不要靠"把每镜都压短"来制造快感**：那是模型过剪切的重灾区。快感来自**镜头数量**，而数量受"多镜单元 ≥10 秒"和"单元 ≤30 秒"两头夹着。一段无台词的戏想更快，就**多切几刀**，而不是让每一刀都只剩 1 秒
- **短镜必须写动作余量**：一个 1.5 秒的耳光要写明分几拍（起手 / 命中 / 余势），否则剪辑没有可切的头尾

**黄金前 7 秒**：如果是第一集或需要抓人的集头，前 7 秒这样排——

| 时间 | 干什么 | 镜头 |
|---|---|---|
| 0–2s | 视觉钩子 | 特写（一滴泪 / 一把刀 / 一巴掌） |
| 2–5s | 台词钩子 | 近景，一句狠台词（"其实孩子是你的"） |
| 5–7s | 悬念钩子 | 特写瞳孔 / 黑场 + 悬疑音效，引导付费 |

**爽点密度**：每个生成单元里至少放一个"钩子"——台词炸点、动作变化、或新道具入画。

## B. 画幅与构图（9:16）

**画幅写死**：`9:16 竖屏`。参考生视频是无锁定任务，不写就没有保障。

**UI 安全区**（短剧独有，必须写进画面描述）：

| 区域 | 内容 | 规则 |
|---|---|---|
| 顶部约 20% | 前摄挖孔、电量条、抖音/快手头像与标题栏 | **眼睛、刀尖、关键道具不能放这里** |
| 底部约 15% | 进度条、点赞评论转发按钮、对白字幕 | **下跪的膝盖、握刀的手等关键动作不能放这里** |

**构图选择**：

- **对话 / 情绪戏（近景、特写）→ 中心构图**：脸放正中间，两眼约在画面上 1/3 处。竖屏窄，脸一偏，另一侧的空白会把注意力"吸走"
- **动作 / 定场戏（全景、中景）→ 三分法**：人物放左或右 1/3 线，视线方向留 2/3 空白
- **视线留白（鼻前空间）**：人物看向哪边，哪边就要留出空间。眼睛到画框的距离应明显大于后脑勺到另一侧的距离。脸贴边 = 观众生理性发堵
- **景别主力是近景和特写**。竖屏里大全景人物看不清，只在需要交代"万人大场面"时才用，且停留不超过 1 秒

**景深写法**：写"浅景深，背景虚化成色块"这类**可执行描述**，**不要写具体光圈值**（F1.2、F5.6 这类数字模型不响应）。同一场戏里景深档位要统一，不要上一个特写极虚、下一个近景全实。

## C. 运镜幅度与镜头语言

短剧的运镜**幅度小、动机强**。手机屏上大调度看不清，反而显得乱。

| 运镜 | 短剧正确用法 |
|---|---|
| **固定** | 主力。对话戏、反应戏的默认选择 |
| **急推** | 身份揭露、瞳孔地震、打脸瞬间 |
| **慢推** | 心机算计、压抑窒息，营造压迫 |
| **拉** | 从局部揭晓全貌（从发簪特写拉到全身华服） |
| **摇** | 审视打量（从鞋摇到脸）；快速摇出残影做转场 |
| **跟** | 后背跟（大佬出场）、碎步跟（哭着奔跑） |
| **环绕** | 情绪峰值处短促环绕，不要绕满一圈 |
| **手持晃动** | 冲突、追逐段落的真实感 |

**铁律**：

- **一镜只写一个主运镜**。写"推进+横移+上摇"模型会糊
- **运镜必须有动机**。没有情绪或信息揭示的运镜，写进去就是让画面瞎晃
- **竖屏忌高角度俯拍人物**——会把人物拍矮、显得猥琐

**切镜点写法**（对应官方的端点纪律）：让每个镜头的句子**结束在动作完成态**，下一镜再开启新动作。写"她抬手，巴掌落下"结束，而不是"她抬手"就切。

## D. 光影与色彩

**基调**：低饱和、高对比的"网感"。不要为了好看把饱和度拉满（那是影楼婚纱照）。皮肤可以冷白，但嘴唇要有血色，不要一片灰白。

**冷暖对冲（短剧最好用的一招）**：用光色区分权力关系，不需要台词。

- 压迫方打冷光（蓝/白），弱势方打暖光（黄/橙）
- **反转时刻把光换过来**——女主身份揭露时，她那边转冷光，对方转暖光。观众看到光色变了就知道攻守易势

**底光**：手电筒/闪光灯从下巴往上打。自然界不存在这种光，大脑会立刻判定"危险/非人"。用于黑化瞬间、悬疑、鬼怪。**慎用**——用多了整部片子变鬼片。

**硬光 / 柔光**：

- **硬光**（影子清晰、明暗交界锐利）→ 危险、阴谋、紧张、对立。写法：`侧面 45° 硬光，脸上半边亮半边黑`
- **柔光**（影子模糊、整体明亮）→ 甜蜜、回忆、温暖、安全。写法：`柔光漫反射，无锐利阴影`

一场虐心吵架戏用柔光拍，观众会觉得"他俩在调情"；一场甜宠告白用硬光拍，观众会觉得"男主图谋不轨"。**不写光质，得到的就是毫无情绪的平光。**

## E. 表演强度

短剧表演是**方波**（瞬间到峰值、瞬间收回、再瞬间到更高峰值），不是电影的抛物线。

三种速度指令，直接写进 prompt：

| 指令 | 写法 |
|---|---|
| **快演** | `台词中间不停顿，语速极快，像机关枪`——吵架、揭露身份 |
| **慢演** | `每句台词后停顿一秒，死盯着对方`——威胁、分手、告别 |
| **碎演** | `边说边做小动作（摸戒指、转笔、抖腿）`——隐藏心机、反派算计 |

**写表情用描述性语句，少用成语**（官方要求）：写 `脸上带着满足的笑容，大口地吃饭`，不要写"津津有味地吃饭"。

## F. 声音设计密度

短剧声音密集，是情绪的放大器。

- **音效提前量**：画面的巴掌还没落，声音提前一点响。听觉比视觉快，会让大脑产生"这一下打得很重"的预期
- **留白声场**：狠台词落地后抽掉所有 BGM 和环境音，只留呼吸声或耳鸣感，短暂静默再切特写加钢琴。静默会让大脑高度警觉，任何细微声音都被放大
- **BGM 硬切**：情绪变了（虐心转甜宠）就硬切，不要淡出淡入。**严禁一首 BGM 铺满全集**
- **内心独白**：处理成"在耳边说话"的近距离感，产生窥私的亲密感

**负向控制必须写**：`不额外加入对白字幕`、`无bgm，只生成环境音和动作音`（按需调整）。不写模型会自己加 BGM 和字幕。

**BGM 卡点**：在分镜表里用相对时间标注 `3秒后鼓点进入`、`第5s重音落在巴掌上`。**不要写"一秒摇头3次"这类频率控制**——官方明确不建议用时间戳控频率。

## G. 短剧专属雷区

| 雷区 | 后果 | 改法 |
|---|---|---|
| 写大全景定场超过 1 秒 | 人物看不清，观众划走 | 换特写；真要交代环境用摇镜头带出 |
| 同一角色同景别硬切（中景切另一个角度的中景） | 视觉跳帧，像剪辑失误 | 中间插手部特写或道具空镜 |
| 连续三个固定机位近景 | 画面"死"了 | 第三个给个微推 |
| 双人对话一直近景正反打超过 3 个回合 | 像新闻联播 | 第三回合切一个反应特写 |
| 台词说完才切 | 节奏拖沓 | 在话尾未落或气口处切 |
| 写了 1 秒以下的镜头 | 模型丢动作 | 单镜不低于 1 秒；要更快就多切几刀，而不是每刀更短 |
| 单元里塞了 4 个以上主体 | 串脸、角色重复 | 按单元拆素材，一场戏只传需要的人 |
