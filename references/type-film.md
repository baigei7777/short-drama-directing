# 电影档（16:9 横屏）

用户回答"做的是**电影**"时读本文件。

---

## A. 切镜速度 / 平均镜头时长

**主力档位：单镜 4–6 秒。** 30 秒的单元放在 **5–7 个镜头**——比短剧少（短剧会切得更碎）。

电影和短剧最本质的区别在这里：**电影的情绪是抛物线**（慢慢起、到峰值、慢慢落），短剧是方波（瞬间到峰值）。所以：

- 不要为了"抓人"把每个镜头都压短。电影的慢是有功能的——给观众时间进入人物
- 情绪值 1–3 的段落单镜可以到 **6 秒甚至更长**，只要这一镜里有一个完整的表演或一个完整的运镜
- 情绪值 8–10 的段落压到 3–4 秒，**动作镜同样可以短**（电影里的打击、爆点镜头也不长）
- 一集/一段里的镜头数**少于短剧**。硬切少、转场少、留白多

**长镜头的处理**：电影是唯一值得用"长镜头"的档位。如果剧本要求一个 10 秒以上的不间断镜头：

- 用**阶段写法**（`Beginning / Then / Finally`）而不是镜头标签
- 明确写 `single continuous take, no cuts`（或中文 `一镜到底，中途不切`）——不写，长动作描述会被模型切碎
- **不要**在同一段 prompt 里混用"一镜到底"和 `镜头1/镜头2` 的硬切标签，模型会混乱
- 提醒用户：2.5 的长镜稳定性会下降，可能需要抽卡

---

## B. 画幅与构图（16:9）

**画幅写死**：`16:9 横屏`。

- **三分法为主**。横屏空间宽，人物放 1/3 线，视线方向留出空间
- **宽构图与留白**：横屏的优势是环境。允许更大的景别（远景、大全景）承载空间叙事——这一点和竖屏短剧完全相反
- **安全区**：不像竖屏那么苛刻，但底部仍要给字幕留位置，不要把那 10% 当关键信息区
- **景深**：写"浅景深，主体清晰背景柔化"这类可执行描述，**不要写具体光圈值**
- **对角线与非对称构图**可以用。电影观众接受更高的构图复杂度

---

## C. 运镜幅度与镜头语言

电影的运镜**敢做大调度**，这是它和短剧最大的差异。

| 手段 | 用法 |
|---|---|
| **推 / 拉** | 慢推给压迫，慢拉给揭示或抽离 |
| **摇 / 移** | 横移带出空间关系；擦肩而过时反派对向入画 |
| **跟** | 长距离跟拍，人物在画内横移 |
| **升 / 降** | 建立权力关系；从跪着的人升起露出高位者 |
| **环绕** | 情绪峰值或揭示时刻，允许绕更多 |
| **俯冲 / 航拍 / FPV** | 建立场景规模 |
| **希区柯克变焦** | 心理冲击 |
| **纵深调度（Z 轴）** | 电影的核心武器。人物由远及近逼近镜头 → 压迫感；转身走入深处 → 被抛弃感 |
| **一镜到底** | 见 A 节的长镜头处理 |

**「先静后动」原则**：前一个镜头是固定机位时，下一个镜头给运动，用动态打破静态。反之亦然。观众在静止画面上停留约两秒后会开始寻找新刺激。

**动接动 / 静接静**：

- **动接动**：剪辑点切在运动趋势中（甩手切甩头），藏剪辑点
- **静接静**：剪辑点切在动作停顿间隙，沉稳、放大表演
- **破格**：激烈的动作后紧接一个安静的细节特写（一根针掉地），反差制造悬念；呆滞凝视后紧接爆发，静为了蓄力

**运镜频率匹配**：前一个激烈猛摇，后一个缓慢横移——虽然都叫"动"，频率不同观众会晕。慢接慢、快接快。

## D. 光影与色彩

**基调**：电影级调色、细腻的胶片质感。允许浓郁的电影级调色和胶片颗粒。

- **硬光**（影子清晰、明暗交界锐利）→ 危险、阴谋、紧张、对立。写法：`侧面 45° 硬光，脸上半边亮半边黑`（伦勃朗光的硬核版）
- **柔光**（影子模糊、整体明亮）→ 甜蜜、回忆、温暖、安全。写法：`柔光漫反射，透过纱帘的自然光`
- **逆光轮廓**：`逆光，人物轮廓镶一道亮边，正面处于阴影中`
- **冷暖对冲**：冷色代表冷酷/压制，暖色代表柔弱/温暖。反转时刻交换冷暖，观众不用台词就知道攻守易势
- **底光**：自然界不存在的光，大脑判定为"危险/非人"。悬疑、黑化、鬼怪用

**不写光质，得到的就是毫无情绪的平光。**

---

## E. 表演强度

**电影表演是抛物线**：情绪慢慢起、到峰值、慢慢落。允许沉浸式的表演节奏。

- 不要写"台词中间不停顿，像机关枪"——那是短剧的快演
- 用**微表情**和**停顿**承载情绪：`她沉默了两秒，喉头动了一下，才开口`
- **写表情用描述性语句，少用成语**（官方要求）：写 `眼角慢慢湿润，嘴角试着往上扬`，不要写"破涕为笑"

---

## F. 声音设计密度

电影**以环境声为主**，BGM 稀疏且克制。

- **环境声铺底**：风声、雨声、远处的城市底噪——这些建立空间真实感，是电影声音的主体
- **BGM 不铺满**：只在关键情绪段进入，其余时间让环境声和静默承担
- **静默是有力的**：台词落地后抽掉所有声音，只留呼吸或耳鸣感
- **声音的空间感**：写清声源位置（`画外传来关门声`、`脚步声从身后逼近`）

**负向控制**：`不额外加入对白字幕`、`以环境音为主，bgm 仅在情绪峰值处进入`（按需调整）。

---

## G. 电影档雷区

| 雷区 | 后果 | 改法 |
|---|---|---|
| 一个镜头塞两个以上主动作 | 模型跳过其中一个 | 拆镜，或改成阶段写法 |
| 混用"一镜到底"和硬切标签 | 模型混乱，切得莫名其妙 | 二选一 |
| 写具体光圈值 / ISO / 传感器型号 | 模型不响应 | 改成"浅景深，背景柔化成色块" |
| 全程高能、没有呼吸段 | 观众疲劳，峰值不炸 | 主动插情绪值 3 分的段落 |
| BGM 铺满全片 | 情绪变成一条直线 | 只在关键段进入 |
| 长镜头没有明确写"不切" | 模型把长动作切碎 | 补 `一镜到底，中途不切` |
