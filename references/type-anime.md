# 动漫档（16:9）

用户回答"做的是**动漫**"时读本文件。

## 先分子分支

**动笔前必须再追问一句**：这次是 **2D 国漫风 / 3D 动画 / 三渲二**？三者的 prompt 词汇几乎不通用，用错会直接毁掉画风。

| 子分支 | 核心原则 | 读哪节 |
|---|---|---|
| **2D 国漫风** | 用**动画制作语言**，禁用摄影机语言 | C 节 |
| **3D 动画** | 用建模/材质/物理光影语言 | D 节 |
| **三渲二** | 3D 建模 + 2D 渲染同时描述 | E 节 |

---

## A. 通用：切镜速度与画幅

**画幅写死**：`16:9 横屏`。

**切镜速度**：介于短剧和电影之间，30 秒单元约 **5–7 个镜头**。

- **台词镜**：被台词长度撑着，台词长度 + 0.5–1.0 秒缓冲
- **动作/战斗段落**：单镜可以短到 **2–3 秒**，靠镜头数量堆速度
- **情绪/对白段落**：偏长（4–6 秒），允许**定格**（held frame）——定格是动画的合法手段，不是缺点
- 想表现"极快的一击"，**优先用冲击帧**（在正常长度的镜头里插入一帧高对比画面），而不是把镜头压到 1 秒——1 秒的镜头模型会丢动作
- 短镜同样要写分拍（动作余量）

---

## B. 通用：声音设计

动漫的音效**风格化优于写实**：

- 拉丝帧配"咻"的风声、冲击帧配尖锐的"叮"、定格时把环境音整体抽掉
- BGM 可以比电影密，但仍要随情绪变
- 内心独白在动漫里很常用，处理成近距离的耳语感

**负向控制**：`不额外加入对白字幕`、`无bgm，只生成环境音和动作音`（按需调整）。

---

## C. 2D 国漫风

### C1. 核心规则（最重要的一条）

**先声明媒介，然后每一句话都留在动画制作的语汇里。**

开头就写：

> `手绘 2D 动画，赛璐璐上色角色置于手绘背景之上`

**绝对不要在 2D prompt 里出现镜头、焦外、景深、焦距、机身这类摄影词汇**——一旦出现，模型会把画面拉向写实渲染或廉价的移轴微缩感。这是 2D 最容易翻车的地方。

### C2. 层语法（2D 画面 = 图层堆叠）

- **赛璐璐角色 + 绘制背景**：`锐利的赛璐璐上色角色，置于柔和的水彩手绘背景之上`
- **背景滚动 / 多层视差**：`手绘背景缓缓平移`、`前景剪影比远处天际线移动得更快`
- **背景定格 + 角色动画**：明确说出**什么保持不动**。定格是这种媒介的特性，不是失败

### C3. 运动语法

- **爆发作画 vs 定格**：交替使用。`她转身时是一段流畅的全动画爆发，随后定格在她的表情上`
- **节奏**：`以二帧一拍的方式动画`（经典赛璐璐节奏）；只有展示性的关键动作才用一拍一
- **冲击帧**：`命中瞬间插入一帧高对比冲击帧`
- **速度线与拉丝**：`冲刺时背景掠过速度线`、`挥拳时手臂拉出残影`
- **跟随动作**：`身体停下后，头发和衣摆继续飘落归位`

### C4. 2D 里的"相机"

2D 的相机是**在美术稿上方移动的摄影台**，不是实拍机位：

- 可以写：`横移扫过手绘背景`、`对着定格的脸缓慢推近`、`沿塔楼美术稿垂直下摇`
- **一镜仍然只写一个主运镜**
- **不要写**推轨车、手持晃动、镜头呼吸这类写实摄影词汇

### C5. 光影与色彩（画出来的，不是渲染出来的）

- `硬边双色赛璐璐阴影`
- `轮廓光作为下颌处一道干净的形状`
- `眼中高光画成一块白色楔形`
- 调色板与质感：`有限色板，温暖的纸张质感`、`平涂色块配手绘光晕`

### C6. 风格安全（重要）

**描述技法、年代、色板——绝不写工作室、作品名或在世画师。**

- ✅ 安全写法：`1990 年代手绘电视动画质感，带颗粒胶片感`
- ❌ 危险写法：写某个具体工作室、某部作品的名字、"像某某的画风"

后者不止有版权风险，还会让模型直接去模仿一个具体的受保护形象。

### C7. 2D 失败与修法

| 症状 | 修法 |
|---|---|
| 画面漂向写实或 3D CG | **删掉所有镜头和景深词汇**；开头改成"手绘 2D 赛璐璐动画"；把背景说成手绘的 |
| 动作发飘、像转描 | 要求"以二帧一拍的利落爆发"，在动作之间加定格，快弧线上加拉丝 |
| 快速动作时脸崩 | 把速度放进线条、拉丝和背景滚动里，不要放在脸部细节上；切到一帧定格冲击帧 |
| 多个镜头之间画风闪 | **在每个镜头里重复同一句媒介声明**，并保持同一个色板短语不变 |

## D. 3D 动画

用**建模、材质、物理光影**语言，而不是 2D 的图层语言。

- **媒介声明**：`3D 动画渲染，PBR 材质，全局光照`
- **材质**：皮肤次表面散射、金属反射、布料编织纹理、毛发/羽毛的独立运动
- **物理光影**：体积光、环境光遮蔽、屏幕空间反射、景深（3D 里景深是合法的，但仍不写光圈数值）
- **运镜**：3D 里复杂运镜和长镜头都成立，类似电影档（见 `type-film.md` 的 C 节）
- **风格安全**：同样只描述技法与质感，**不要写具体作品/工作室**。写"国风 3D 动画，写实质感，暖金色调"这类描述
- **通用雷区**：写"NPR"却又要照片级真实感，两者会互相打架——二选一时明确选一个

---

## E. 三渲二

3D 建模 + 2D 渲染。**两部分都要点到，缺一个就会偏**：

- **建模部分**：`3D 建模，模型结构清晰，能看出体积和转折`
- **渲染部分**：`卡通渲染，硬边赛璐璐明暗二分，轮廓线描边`
- 关键词：`卡通描边`、`赛璐璐明暗二分`、`色块平涂 + 3D 体积感`、`手绘质感贴图`
- **注意**：不要写"手绘 2D 动画"——那会让模型放弃 3D 结构；也不要只写"3D 渲染"——那会丢掉描边和二分
- **运镜**：可以像电影一样调度，因为底层是 3D 结构

---

## F. 动漫档通用雷区

| 雷区 | 后果 | 改法 |
|---|---|---|
| 2D 里写了镜头/景深/焦外词汇 | 漂向写实渲染 | 全删，改成动画制作词汇 |
| 写具体工作室/作品/画师名 | 版权风险 + 形象被模仿 | 改成技法 + 年代 + 色板 |
| 多镜 prompt 里媒介声明只写一次 | 画风在镜头之间闪 | **每个镜头都重复同一句媒介声明** |
| 三渲二只写了 3D 或只写了 2D | 偏成纯 3D 或纯 2D | 两部分都点到 |
| 用缩短镜头表现"极快的一击" | 模型过度剪切 | 用冲击帧，镜头保持 2 秒以上 |
| 写了 1 秒以下的镜头 | 模型丢动作 | 单镜不低于 1 秒 |
