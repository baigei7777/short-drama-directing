# 视听语言词库（已转译成 prompt 可写的样子）

从真人实拍术语转译而来。原则：**官方允许直接写的词直接用；小众专业词必须写成 `[名词 + 描述性解释]`。**

> 判断标准很简单：**一个没学过电影的人听到这句话，能不能大致想出画面？** 能，就直接写；不能，就补解释。

---

## 1. 景别

| 词 | 可直接写？ | 竖屏（9:16） | 横屏（16:9） |
|---|:---:|---|---|
| 大全景 | ✅ | 慎用，人物看不清 | 主力，交代空间 |
| 全景 | ✅ | 动作定场（打架、下跪、扇巴掌的起始） | 常用 |
| 中景 | ✅ | 叙事主力，交代双人站位与手部互动 | 常用 |
| 近景 | ✅ | 情绪主力，怼脸拍微表情 | 常用 |
| 特写 | ✅ | 反转、扎心台词、流泪瞬间 | 常用 |
| 大特写 | ✅ | 眼睛、手、道具局部 | 局部强调 |

**写法**：`特写`、`近景`、`从中景切到特写`。

---

## 2. 运镜（官方可直接写）

推 / 拉 / 摇 / 移 / 跟 / 环绕 / 俯冲 / 后拉 / 上摇 / 手持晃动

热门运镜也可直接写：一镜到底 / 希区柯克变焦 / 航拍视角 / FPV / 子弹时间 / 手持镜头 / 回弹变速

**铁律：一个镜头只写一个主运镜。** 写"推进+横移+上摇"模型会糊。

---

## 3. 机位

低角度 / 俯视 / 第一人称（POV）/ 平视 / 过肩

**POV 补充**（这一节原本缺失，现在补上）：

- **仰拍给权力**：低角度仰拍让人物显得高大、有压迫
- **俯拍给卑微**：俯视让人物显得弱小
- **POV 给代入**：第一人称视角让观众变成角色本人
- **POV 连续不要超过 3 秒**，超过观众会失去空间参照；POV 之后要给一个不含 POV 的镜头重置空间
- 竖屏里**不要高角度俯拍人物**，会把人拍矮、显得猥琐

---

## 4. 构图

- **中心构图**：脸放画面正中，两眼约在上 1/3 处。竖屏的对话/情绪戏首选——竖屏窄，脸一偏另一侧空白会把注意力吸走
- **三分法**：人物放左或右 1/3 线。横屏主力；竖屏用于动作/定场戏
- **视线留白（鼻前空间）**：人物看向哪边，哪边就留空间。眼睛到画框的距离要**明显大于**后脑勺到另一侧的距离。脸贴边 = 观众发堵
- **UI 安全区**（竖屏必写）：顶部约 20% 不放眼睛/刀尖/关键道具；底部约 15% 不放关键动作

**写法**：`中心构图，人物面部位于画面中央`、`人物位于画面左侧三分之一，视线朝右，右侧留出大片空间`。

---

## 5. 光影

| 写什么 | 怎么写成 prompt |
|---|---|
| 硬光 | `侧面 45° 硬光，脸上半边亮半边黑` |
| 柔光 | `柔光漫反射，通过纱帘的自然光，无锐利阴影` |
| 冷暖对冲 | `左侧冷蓝光，右侧暖橙光，冷暖对撞` |
| 逆光轮廓 | `逆光，人物轮廓镶一道亮边，正面处于阴影` |
| 底光 | `光从下巴下方往上打，形成不自然的底光` |
| 伦勃朗光 | `伦勃朗光，面部一侧三角光斑` |

**硬光 = 危险/阴谋/紧张/对立；柔光 = 甜蜜/回忆/温暖/安全。** 不写光质，得到的就是毫无情绪的平光。

---

## 6. 景深（转译要点）

**不要写具体光圈值（F1.2、F5.6 这类模型不响应）。** 写成可执行描述：

| 原实拍说法 | 转译后的 prompt 写法 |
|---|---|
| 景深 1 档（F4–F5.6，实） | `画面全实，背景清晰可见` |
| 景深 2 档（F2.8，中虚） | `浅景深，背景模糊但能看出人形` |
| 景深 3 档（F1.2–F1.8，极虚） | `极浅景深，背景完全虚化成色块` |

**同一场戏里景深档位要统一**，不要上一个特写极虚、下一个近景全实。

---

## 7. 纵深调度（Z 轴，横屏的强项）

写"人动"，不是"镜头动"：

- **逼近镜头**（由远及近）：`人物从画面深处一步步走向镜头，身形逐渐占满画面` → 大脑判定"有东西在逼近我"，压迫感
- **远离镜头**（由近及远）：`人物转身朝画面深处走去，身影逐渐变小` → 被抛弃感
- 竖屏里 Z 轴比 X 轴（左右横移）更有冲击力——竖屏窄，横移容易出画，前后移动能吃满纵深

---

## 8. 方向一致性

- **黄金法则**：主角第一次从画面左侧入画，之后尽量保持左入右出，维持方向惯性
- **破格暗示转折**：角色黑化/下决心的那一刻，改成从右侧入画，观众潜意识会收到"这个人不一样了"的信号
- **写法**：`人物从画面左侧入画，向右侧走出画面`

---

## 9. 情绪标尺（1–10 分）

填进分镜表，用来对齐切镜速度：

| 分值 | 场景 | 单镜时长 | 切法 |
|:---:|---|---|---|
| 1–3 低 | 日常对话、走路、铺垫 | 4–6s | 固定机位，静接静 |
| 4–7 中 | 争执、怀疑、谋划 | 台词镜 4–5s；动作/反应镜 2–3s | 正反打近景，轻微推拉 |
| 8–10 高 | 打脸、下跪、揭秘、死亡 | 台词镜 3–5s；**动作镜可到 1.5–2s** | 特写急推，动接动，音效炸点 |

> 注意：情绪值高 ≠ 每镜都短。**台词镜压不动**（长台词自然撑出长镜），真正能压短的只有动作镜和反应镜。

连续三个单元都在 9 分，观众会累。**主动插一个 3 分的单元让人喘口气**，后面那个 9 分才炸得起来。

---

## 10. 转场（必须写清触发点）

官方要求：**转场要写清触发点与方式**。

| 转场 | prompt 写法 |
|---|---|
| 硬切 | `第5s 硬切到下一镜` |
| 遮挡转场 | `手掌完全遮满画面后切下一场` |
| 快速横移 | `第5s 快速向左横移转场（向左擦除 + 自然叠化）` |
| 动作匹配 | `上一镜扔出匕首的手部动作，下一镜接住酒杯的手部动作，两个动作同步` |
| 图形匹配 | `上一镜圆形的钟表，下一镜切圆形的车轮` |
| 闪白 | `闪白过渡，两帧`（回忆、惊醒、晕厥用闪白，比闪黑更有冲击） |

---

## 11. 越轴与机位跳变（转译要点）

原实拍术语在这一节最容易直接照抄进 prompt，**但模型不认**。转译规则如下。

**越轴** → 不写"越轴"，改成**明确声明每个角色的视线方向，并在换机位时保持同一方向描述**：

```
林晚始终看向画面右侧（朝着周砚），周砚始终看向画面左侧。
机位换到林晚侧后方，林晚的视线方向不变。
```

更好的做法是**用站位参考图直接约束**（见 `ref-binding.md`）。

**30° 原则 / 机位跳变** → 度数写进 prompt 模型不一定响应。把度数留在**分镜表**里给人看，prompt 里写可执行表述：

```
机位角度明显改变（由正面机位移到侧后方机位），同时景别从近景变为特写。
```

**"角度变化 + 景别变化"一起写**，跳切感就成立——景别变了，大脑不会把角度不足判断成卡帧。

---

## 12. 连续性锁（跨镜不能变的东西）

AI 生成里跨镜一致性全靠 prompt 反复声明。每个单元里，下面这些要在**每个镜头**都提一次：

- 发型、发饰
- 服装、领口、配饰
- 伤痕/血迹的**位置与颜色**（位置变了就是穿帮）
- 手里拿的东西在哪只手
- 人物的站位与视线方向

**写法**：`全程林晚左手持手机，发型与服装保持不变`（贯穿声明只写一次，放在结尾的【整体要求】里）。

## 13. 表演

### 13.0 核心公理

> **表演是"压力下的行为"，不是"情绪的展示"。**
> 角色**想要**什么 → 有什么在**挡着** → 他为此**做了什么**。情绪是这场角力的副产品。

**但形式必须守官方那条硬要求**：*动作优先概括性描述，表情写描述性语句、少用成语。*

所以本节的写法是——**形式不变（描述性语句），内容换掉（写行为，不写情绪）**：

| ❌ 写情绪（旧写法） | ✅ 写行为（现在） |
|---|---|
| 她很生气 | 她把杯子往桌上一顿，杯底磕在瓷面上，声音比她预想的大 |
| 不要演出畏缩 | 他一动不动，把视线钉在对方脸上，手垂在身侧没有抬起来 |
| 笑意要凉不要狠 | 他笑了一下，但眼睛没有跟着笑——视线从对方脸上滑过去，落在门口 |
| 她很紧张 | 下唇在抖，喉结重重滚动一下，用嘴长长吸了一口气 |

**关键**：不要写"他很紧张"这类**结论**，要写**能看见的身体标记**。

---

### 13.1 五支柱

**场上每一个角色**都要能拆成这五样。缺一样，表演就塌。

| 支柱 | 是什么 | 怎么写 |
|---|---|---|
| **目标** | 他在这场戏里、**对着某个具体的人**想要什么 | **必须是动词、指向对方**：`让他闭嘴`、`逼他认错`、`求他给一周时间`。**不能是状态**（"很生气""感到内疚"——状态无法直接演） |
| **障碍与赌注** | 什么挡着他；拿不到会怎样 | 外部障碍（对方想要相反的、旁边有人看着、只剩两小时）+ 内部障碍（自尊不让他低头）。**赌注 = 失败的代价，代价必须让他害怕** |
| **策略** | 此刻追目标的具体手段 | **动作动词**：逼问、讨好、羞辱、哀求、挑衅、讲价、威胁、拖延。**策略失败时，活人会换策略** |
| **节拍** | 他想要一件事、用一种方式的**最小单位** | 节拍在以下时刻结束：目标达成 / 策略失败 / 新信息到达 / 权力关系翻转。**每一次节拍变化都必须在行为上看得见**（一个停顿、姿态变化、语速变化、视线转移）。一场戏 **2–4 个节拍变化**；全程行为不变 = 演平了 |
| **潜台词** | 他真正想的，和他嘴上说的**不一样** | **潜台词不是"演"出来的**，是他在说假话的同时追真目标时**自己漏出来的**。可写进戏里的标记：**不成问题的问题**、**重复问同一件事**（说明他不信答案）、**突然换话题**、**不合时宜的玩笑**（挡脆弱）、**过短的回答**（"行。""随便。"——一扇关上的门） |

> ⚠️ **节拍和"情绪值"是两套东西**：节拍管"**这个单元里该在哪切**"，情绪值（第 9 节）管"**这一档该多快**"。两者并用，不要混。

---

### 13.2 倾听与反应（表演质量的主要考场）

**表演不在台词里，在台词之间。** 四个可观察的标记：

1. **反应先于对方台词结束**——一个人在半句话里就听懂了，脸和身体已经开始回应。**对方说完才"切换"表情，是死表演。**
2. **先想后说**——回答一个难问题之前，有一个极短的停顿，能看见他在**决定要说什么**。秒答且语速均匀 = 背台词。
3. **消化时刻**——重要的事发生了（消息、威胁、羞辱），角色需要时间**咽下去**。从零点几秒到一个长停顿都算。**别让角色立刻"恢复"。**
4. **被对方传染**——语速、音量、能量跟着对方变：喊声要么被喊回去，要么被刻意的安静压住——**总之要有回应，不要各说各的**。

---

### 13.3 身体

**身体先于心理。** 第一个字说出来之前，身体已经在讲故事。

| 参数 | 高 / 前 | 低 / 后 |
|---|---|---|
| **重心** | 胸口、下巴抬起 → 自信、攻击性、地位 | 肩膀、含胸 → 疲惫、恐惧、服从 |
| **节奏** | 快、碎 → 紧张、亢奋 | 慢、省 → 控制、威胁（**最危险的人动得最少**） |
| **开放度** | 肩打开、掌心朝外 | 抱臂、低头、收拢的姿态 |
| **呼吸** | 浅、急 → 恐慌 | 深、慢 → 控制。**呼吸是最诚实的状态指标**；气憋住 = 表演憋住 |

**声音与物理要匹配**：刚跑完的人不可能用平稳的声音说话。

**「手上有活」（Business）**：角色几乎总需要**在做一件事**——不是"在对话"，而是修东西、数钱、擦杯子，**然后一边说**。
- 手上忙着真事，假的戏剧腔就没了
- 停顿被动作填住，节奏就出来了
- **他"怎么"数钱，比他说什么更有潜台词**

> **打断动作规则（最强的重音）**：角色**停下手里的活**的那一刻最有力量。
> 如果在切面包时停在一个词上——**那个词就变成了事件**。用"停"当标点。

**距离即戏剧**：两人的距离就是关系的可见图表。亲密区（<0.5m）/ 个人区（0.5–1.2m）/ 社交区（1.2–3.5m）/ 公共区（3.5m+）。
**去凑近谁、谁打破距离、谁僵住不动——这本身就是一场戏。距离改变 = 节拍改变。**

**地位**：地位是**做什么**，不是**是谁**。
- 高地位：头不怎么动、动作慢、长时间凝视、回答前先停顿、占空间、动别人的东西
- 低地位：手忙脚乱、频繁摸自己（脸、头发）、语句破碎、赔笑、用眼睛请示
- **最有意思的是"地位破裂"**：老板怕了一秒；跟班突然不笑了。一场好戏的形状是**高进低出**，或者**低进翻盘**。

---

### 13.4 说话

- **节奏写在文本里**——精确交付；**快 ≠ 糊**
- **音量对比：最可怕的话说得最轻。** 喊叫是弱者的货币；**控制全场的人压低音量，所有人会凑过来听**
- **停顿是事件，不是窟窿**：停顿里必须有东西在发生（一次判断、一个决定、一次拒绝回答），否则删掉
- **真实的话有杂质**：打断、听半句、重复、说到一半停住。**句子太完整，街头味就没了**
- **台词落在说话人出镜的那个镜头里**（硬规则 5）；OS 嘴不动

---

### 13.5 眼神生命

> **死鱼眼是 AI 生成表演的头号破绽。** 眼睛必须是活的。

- **视线持续微动**——眼睛会飘、思考时会移开、扫到某个细节再收回来。**永远不要冻结在一个点上**
- **眼睛先于头**——视线比头先到达目标。**念头在眼睛里先于台词出现**
- **catchlight 要活**——眼睛要读起来是湿润的、有光的
- **"不动"是选择的，不是死掉的**——如果要演捕食者式的冷静，让眨眼变少、变慢、**有意图**，并且视线仍在缓慢移动

> ⚠️ **降级项**：原体系的"眨眼频率/微眼动量化"（如"压力下快速连眨"）属于**极高风险的微表演**，与本技能记录过的"泪珠生成常崩"同类。**上述四条可执行的照写；量化的频率控制列为可选，模型未必响应。**

---

### 13.6 状态而非过渡

> **模型拍不好"过程"，拍得好"状态"。**

写角色**已经处在那个动作状态里**：`已经挥到一半`、`拳头已经出去`、`正在踱步`、`正在争吵`——**不要写"伸手进包里、掏出来、抡起来"这个过程叙述**（过程会崩，状态会成）。

**用逐拍的状态链接，不要叙述连续过程。**

> 📌 **作用域说明（重要，不要误读）**：
> 这条只管 **prompt 文本里怎么写动作**。
> 本技能在**拍摄备注**里写的"分拍"（`0–0.4s 起手 → 0.4–0.8s 命中 → 余势`）**不进 prompt**，是给剪辑留可切头尾用的。**两者不冲突。**

---

### 13.7 群戏与空间

- **群体反应是波浪，不是同步。** 第一个人先懂，第二个慢半拍，第三个根本没懂。**同时同幅度的反应看起来很假**（除非刻意做喜剧同步）
- **反应比动作值钱。** 每件事发生之后，最有价值的一帧是**看见它的那个人的脸**
- **威胁时全体静止。** 平时的琐碎小动（挪重心、比划、前倾）在关键威胁的瞬间**全部停住**。**由动到静的对比就是标点**
- **移动即动机。** 没人会无缘无故穿过房间：要么**朝向**什么，要么**离开**什么。强动机事件——逼近（升级）、转身背对（打发走 / 藏脸）、对方坐着时站起来（夺权）、冲突中坐下（悖论式权力）、停在门口（门槛=决定点）、开始收拾东西（用身体下最后通牒）
- **强者静而轻，弱者躁而响。** 危险不是由危险的人演出来的，是**周围所有人的紧张**演出来的
- **威胁不预热**：**不要**用"威胁性的停顿、眯眼、缓慢转头"来预告暴力。**真实的暴力不打招呼就来了**
- **衰退会累积。** 角色被一路磨损时，要**累积地**带在身体里（更灰、更重、反应更慢），**不可以在场景之间重置**

### 13.8 坏表演图鉴（认出来 → 在 prompt 层面修）

| # | 症状 | 长什么样 | prompt 级修法 |
|---|---|---|---|
| 1 | **指示性表演**（挤表情） | 脸在"描绘"情绪：眉毛高挑、挤眉弄眼 | **把脸从任务里拿开**：写目标，把手给他一件事做 |
| 2 | **演结果** | 从第一秒就演出这场戏的结局 | 只写角色**此刻知道的** |
| 3 | **等提示** | 对方说话时一张空脸 | 把反应写成**从对方半句话时就开始** |
| 4 | **单一策略** | 全场一个颜色（一直吼 / 一直哭穷） | 标出节拍，每个节拍换一个策略动词 |
| 5 | **手势图解台词** | 说"大"就张开双臂 | 手势要么**先于**念头、要么**与台词矛盾**、要么**干脆没有** |
| 6 | **凭空的情绪** | 没有铺垫、没有触发事件的泪或怒 | 搭梯子：**克制 → 断裂**；情绪必须有代价 |
| 7 | **身体与履历不符** | 混混有舞者的体态；瘾君子有崭新的皮肤质感 | 设定身体档案：重心、节奏、磨损感 |
| 8 | **说话太干净** | 街头角色说书面长句 | 给台词加杂质：打断、说半句、重复 |
| 9 | **预告威胁** | 暴力前的"威胁性"停顿、眯眼、缓慢转头 | 威胁是平常的；暴力不预热 |
| 10 | **同步群戏** | 所有人同时同样地反应 | 反应成波浪，幅度各异 |
| 11 | **死停顿** | 静默里什么都没发生 | 用判断或动作填满——否则剪掉 |
| 12 | **情绪重置** | 强烈事件后瞬间"恢复" | 状态有惯性，余势带进下一拍 |
| 13 | **点评角色** | 表演在朝观众眨眼（"我们都知道这很好笑"） | 完全相信情境；**喜剧要极认真地演** |
| 14 | **特写过载** | 特写里还在做丰富的表情 | **镜头越紧，动作越少**：只留眼睛和念头 |
| 15 | **死鱼眼** | 凝视冻结、不眨眼、没有视线移动、catchlight 发死 | 完整执行 13.5——**眼神生命不是可选项** |

### 13.9 表演完成度（0–5，主观自检）

| 分 | 名称 | 特征 |
|:---:|---|---|
| 0 | 人偶 | 台词念了，行为没有 |
| 1 | 朗诵者 | "有表情"的台词、指示性的情绪、图解台词的身体 |
| 2 | 勤勉 | 能猜出目标，但只有一种策略、反应迟、停顿空 |
| 3 | 匠人 | 目标和节拍都在，会听对手，身体说得通。**缺**：潜台词、意外的策略、状态惯性 |
| 4 | 活的 | 行为连续、策略有反差、潜台词与台词背离、地位在身体里、反应先于台词、至少有一个"意外但真实"的选择 |
| 5 | 磁石 | 4 的全部 + **悖论**：同时演两个真相（一边帮一边恨；一边道歉一边辩护；一边爱一边已经离开）。**单一而干净的情绪在特写上会显得塑料** |

> 📌 **这是主观自检参考，不是硬门槛。** 本技能真正可脚本化的是「覆盖率校验」与「格式校验」两道门。
> 原体系的"每个英雄镜头瞄准 4 分以上"降级为**建议值**。

### 13.11 节奏档（短剧常用，保留）

三档速度指令**保留**，但作为**节奏档**使用，不再是表演的全部：

- **快演**：`台词中间不停顿，语速极快，像机关枪` —— 吵架、揭露身份
- **慢演**：`每句台词后停顿一秒，视线不离开对方` —— 威胁、分手、告别
  > ⚠️ 原写的是"**死盯着**对方"，已改成"视线不离开"。停顿里**必须有内容**（一次判断、一个决定），否则是死停顿（第 11 号坏表演）。
- **碎演**：`边说边做小动作（摸戒指、转笔、抖腿）` —— 隐藏心机、反派算计
