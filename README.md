# short-drama-directing

把一份**剧本 + 一集配音 + 一套参考图**，变成两份可以直接用的东西：

- **分镜表**（给人看）：每个生成单元里有哪些镜头、各自多长、画面是什么
- **prompt 清单**（给机器用）：每个生成单元一条，可以直接粘进 **Seedance 2.5**

面向 **短剧（9:16 竖屏）/ 电影（16:9）/ 动漫（16:9，2D·3D·三渲二）** 三档。

---

## 它是怎么工作的

核心结构是两层：

```
生成单元（≤30 秒，一次 Seedance 生成任务，含多个镜头）
    └── 镜头（一镜 = 一次切视角的时机）
```

1. **先问类型** —— 短剧 / 电影 / 动漫（动漫再问 2D / 3D / 三渲二）。三档的切镜速度、画幅、运镜、光影、表演、声音密度都不同，不问就写会写成四不像。
2. **按叙事/场景切生成单元** —— 换场景、换情绪、换人物组合就断开，不硬凑 30 秒。
3. **单元内切镜** —— 每镜时长 = 这一镜在成片里应该占多久。台词镜被台词长度撑着，动作镜和反应镜可以短到 1.5 秒。
4. **从配音倒推时长** —— 台词落在说话人出镜的镜头里。
5. **产出两份文件** —— `<集号>-分镜表.md` + `<集号>-prompts.txt`。

## 前提与边界

**需要用户提供**：剧本、每集配音音频、参考图（人物 / 场景 / 站位）。

**本技能不做**：不出图、不出配音、不改剧本、不写真人实拍流程（场记单、通告单、素材命名这些在 AI 生成里没有对应物）。

**默认一次做一集**；用户要做整部时，先出全剧资产总表，再逐集推进。

## 六条硬规则

1. 时间轴必须连续，不许跳段（`0-3s / 3-7s / 7-12s`）
2. 每镜时长 = 成片实际需要；台词镜被台词长度撑着，**动作镜可以短到 1.5 秒**。三条硬约束：单元 ≤30 秒 · 多镜单元 ≥10 秒 · 单镜 ≥1 秒
3. 参考素材按上传顺序编号并在文本里逐一绑定；**不要靠图片上的文字区分角色**
4. 参考生视频是"无锁定"任务，画幅要写死在 prompt 里
5. 台词写在说话人出镜的镜头里
6. 负向控制要显式写（不要字幕、不要多余 BGM）

**平台会更新。** 上面每份来源都有时间戳，隔久了值得回去核对。

### 两份来源之间的一处真实冲突

中文区官方示例用 `【】` 做**结构小标题**（`【主体设定】`、`【分镜头】`），而伙伴向导用 `【】` 表示**画面上的文字**（字幕）。两者会撞车。

本技能的取舍：结构小标题继续用 `【】`（中文官方示例就是这么用的），但**画面上的文字不靠方括号表达**，额外用一句话说清楚——"画面中显示一行文字：'……'"。这样两种理解都不会出错。

## 已知限制

- **配音时间码**：如果用户拿不到每句的精确时间码，本技能按字数为基线估算（中文常态约 4–5 字/秒），并全部标 `待核` 提醒校对。估值不是事实。
- **长镜头**：Seedance 2.5 的长镜稳定性会下降，可能需要抽卡。
- **长台词压不动**：单镜上限约 6.5 秒，所以超过约 40 字的台词必须拆成两镜（**中间不能有呼吸断点**，两镜的人物位置与光向要一致）
- **2D 动画**：prompt 里一旦出现镜头/景深/焦外这类摄影词汇，画面会漂向写实渲染。
