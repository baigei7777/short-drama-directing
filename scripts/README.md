# scripts —— 零依赖工具集

**不需要 npm、不需要 Python**，只用 Node 内置模块（`fs` / `zlib` / `path`）。
每个脚本都靠**命令行传参**，不写死任何项目路径，所以换剧本、换目录都能直接用。

---

## 两道门（每集交付前必跑）

| 脚本 | 干什么 |
|---|---|
| `check-coverage.js` | **第一道门：剧本覆盖率**。逐条比对剧本台词与分镜表，找出漏掉的剧情 |
| `check-storyboard.js` | **第二道门：格式一致性**。素材编号、时间轴、时长、列数、备注、分镜表↔提示词 |

```bash
# 第一道门：漏没漏剧情
node scripts/check-coverage.js 剧本-结构化.json 01-分镜/

# 第二道门：格式对不对
node scripts/check-storyboard.js 01-分镜/
```

> **两道门都要过。** 第一道门全绿但格式错，片子出不来；第二道门全绿但漏了剧情，片子是残的。
> **两个脚本都会打印「被检查了多少项」——计数为 0 说明校验器失效了，不是数据干净。**

## 流水线（换新剧本时按顺序跑一次）

```
剧本.docx
  │
  ├─ docx2txt.js        →  剧本-全文.txt
  │     node scripts/docx2txt.js 剧本.docx 剧本-全文.txt
  │
  ├─ parse-script.js    →  剧本-结构化.json
  │     node scripts/parse-script.js 剧本-全文.txt 剧本-结构化.json
  │
  ├─ inventory.js       →  资产清单草案（人物 / 地点 / 道具 / 标记）
  │     node scripts/inventory.js 剧本-结构化.json 资产清单草案.md
  │
  └─ gen-voice.js       →  配音资产清单（每集字数 / 估算时长 / 说话人）
        node scripts/gen-voice.js 剧本-结构化.json 配音资产.md
```

## 每集开工用

| 脚本 | 干什么 |
|---|---|
| `dump-ep.js` | **导出某一集的完整内容**（场次 / 台词 / OS / 动作 / 标记 / 字数 / 时长估算），可选做全剧关键词检索 |

```bash
# 做第 7 集之前，先把它跑一遍，拿到该集全文
node scripts/dump-ep.js 剧本-结构化.json 7

# 顺便在全剧检索一个词（例：查某个设定从第几集开始出现）
node scripts/dump-ep.js 剧本-结构化.json 7 女装
node scripts/dump-ep.js 剧本-结构化.json --search 女装
```

> **这是每集开工的第一步。** 不要直接在几十万字的剧本里翻。

## 剧本格式要求

`parse-script.js` 认这套中文短剧常见写法：

| 剧本里 | 识别为 |
|---|---|
| `第 N 集` | 集 |
| `N-M，地点，时间，内/外` | 场 |
| `△动作描述` | 动作行 |
| `「音效」` | 音效 |
| `【标记】` | 标记（闪回、字幕、卡点） |
| `角色（表演提示）：台词` | 台词（提示含 `OS`/`内心`/`画外` 则标记为内心独白） |
| `角色：台词` | 台词 |

格式不同就改 `parse-script.js` 顶部的 `EP_RE` / `SCENE_RE` 和台词那两段正则。

---

## 分镜表格式要求

`check-storyboard.js` 校验的分镜表是**13 列**：

```
单元 | 镜号 | 时间轴 | 时长 | 景别 | 运镜·机位 | 画面内容 | 台词 | 音效 | 参考素材 | 衔接 | 情绪值 | 拍摄备注
```

行必须以 `| U` 开头（单元号形如 `U07-03`），时间轴形如 `0-4s` 或 `1.5-4.5s`。
单元块以 `## 单元 U07-03 ...` 开头，块内要有 `**上传顺序**：1) 图-xxx  2) 音频-xxx` 行。

改列数就同步改脚本顶部的 `COLS`。

## 实测过的坑

1. **校验器会静默失效**。改了时长写法（整数 → 小数）而正则没跟上，会导致**被检查项变成 0、所有校验静默跳过**，脚本照样打印"全部通过"。所以每个脚本都会打印计数——**看到 0 就要警觉**。
2. **覆盖率比对要只取引号内的对白**。取整格文本的话，长台词被拆成两镜时，中间的时长标注会打断连续性，产生假阳性。
3. **Windows 控制台是 GBK**，中文输出可能显示成乱码——那是显示问题，文件本身是 UTF-8。用 `read` 类工具看文件即可。
